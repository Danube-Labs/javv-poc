# Supported versions

This page lists the scanner versions and the OpenSearch version that this release of JAVV pins and
supports.

JAVV publishes a scanner image for each supported version, as
`ghcr.io/danube-labs/javv-scanner-{trivy,grype}:<version>`. The
[`javv-scanner` chart](../deploy/helm/javv-scanner/README.md) runs the current version. To run a
different supported version, set it in the chart.
