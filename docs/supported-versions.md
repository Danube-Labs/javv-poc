# Supported versions

The scanners and the OpenSearch version this release of JAVV pins and supports. The scanner
images are published for each supported version as
`ghcr.io/danube-labs/javv-scanner-{trivy,grype}:<version>`; the
[`javv-scanner` chart](../deploy/helm/javv-scanner/README.md) runs the current one unless you set
another.
